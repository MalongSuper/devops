# DevOps, MLOps & AI Platform

This repository contains code and utilities for DevOps, MLOps, and AI platform operations.

It focuses on interacting with APIs and managing cloud services and platforms, such as Azure and other cloud providers. The code is primarily designed for automation, integration, and infrastructure operations rather than producing standalone outputs.


### Scope

- DevOps: Automation, infrastructure, and operational tools.
  
- MLOps: Tools and integrations for machine learning workflows and platforms.
  
- AI Platform: Code for interacting with AI services, APIs, and cloud platforms.
